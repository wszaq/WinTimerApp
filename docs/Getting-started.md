# Getting started

Run the standalone `WindowsTimerApp.exe` on 64-bit Windows. To run the app from source, use the [README instructions](../README.md#run).

1. Choose **15 min**, **30 min**, **1 hour**, or **2 hours**. For a different duration, enter 1 to 1440 whole minutes in **Custom minutes**.
2. Select **Start shutdown timer**. The window shows the remaining time and the planned shutdown time.
3. To stop the countdown temporarily, select **Pause timer**. Select **Resume timer** to continue.
4. To stop the shutdown, select **Cancel timer** before the countdown ends.

At zero, the app requests a Windows shutdown. Save your work before the timer ends.

Minimize the window to hide it in the system tray. Double-click the tray icon to open the window again. You can also right-click the icon and select **Open timer**, **Cancel timer**, or **Exit**. Closing the app ends the countdown.
